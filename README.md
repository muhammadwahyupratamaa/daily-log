# daily-log

One short note a day about what I'm learning as a backend developer.

Each entry is a Markdown file in `logs/<year>/<month>/`: what I learned, what broke, how I fixed it, and what I want to try next. Some notes are rough, because I write them while still figuring things out.

## What I write about

- SQL and PostgreSQL (joins, indexes, transactions)
- Node.js and Express (middleware, auth, error handling)
- Go (the basics, compared with Node.js)
- Testing and debugging
- Docker and CI with GitHub Actions
- Technical English

## What's in here

- `logs/`: the daily notes
- `log.sh`: a small script that creates the day's file, opens it for me to write, then commits and pushes once I save.
